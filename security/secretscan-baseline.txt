# secretscan baseline — fingerprints of findings accepted on purpose.
#
# A baseline lets a KNOWN-SAFE finding stop being reported, so the tool's exit
# status means "something new" rather than "the same thing as yesterday". Without
# it, one accepted fixture keeps the gate permanently red and people stop reading
# the output -- which is worse than not having the tool.
#
# Format: <rule>:<sha256-prefix-of rule+value>. One per line, # for comments.
#
# To add a finding you have reviewed and accepted: run `secretscan --all .`,
# confirm the row is genuinely safe, then append its fingerprint here.
#
# NEVER add a LIVE row without reading the actual value first. The fingerprint is
# derived from the secret, so baselining something you did not look at is
# assuming, not deciding.
